# A Declaration Does Not Determine an Install — reproduction

Issue #149. Every number in `manuscript.md` is a function of two committed snapshot files and
nothing else. This document says how to regenerate them and what output to expect.

## One command

```sh
sh reproduce.sh
```

Runs all seven steps and exits with the number of failed steps (0 = all passed). A full run takes
about 35 minutes, almost all of it step 4 (the depth-2 enumeration).

```sh
sh reproduce.sh --fast
```

Skips the depth-2 enumeration, reporting it `NOT RUN`. Steps 1–3, 5, 6, 7 are unchanged, so the
depth-1 rates, the decay curve, the certificate gate and the citation gates all still run.

## Expected output

| step | what it checks | expected |
|---|---|---|
| 1 | snapshot pins | npm `e5760d09…`, PyPI `bcb64650…` — the snapshots ship with the paper |
| 2 | known-answer plants | `ambiguous.py` 7/7, `depth2.py` 3/3, `decay.py` 7/7 |
| 3 | depth-1 rates | npm 322/2427 = 0.133 [0.120, 0.147]; PyPI 213/226 = 0.942 [0.904, 0.966] |
| 4 | depth-2 certificate | `NOT RUN` under `--fast`; medians and prices on a full run |
| 5 | decay | npm `exact` 1.000 (n=582), `tilde` 0.980 (n=51), `caret` 0.781 (n=439), decl 0.767 (n=150) |
| 6 | corpus gates | C1–C5 pass; `reference-check.md` regenerates byte-identically |
| 7 | manuscript citations | 102 cited of 102 placed; `references.md` matches the corpus |

Exact lines are printed by each step; the numbers above are what they print.

## What each artifact is

| file | is | is not |
|---|---|---|
| `snapshot_npm.json`, `snapshot_pypi.json` | the population, pinned by content hash | a sample |
| `rates.json` | depth-1: evaluable edges, ambiguous edges, closure differences | a resolver trace |
| `depth2.json` | depth-2: exact enumeration and the certificate's price | regenerated by `--fast` |
| `decay.json` | the 12-month survival curve by stratum, with its at-risk set | a curve without denominators |
| `reference-check.md` | the reference corpus: per-entry verification, placement, prune reasons | hand-edited |
| `references.md` | the numbered reference list | hand-typed |
| `manuscript.md` | the paper | generated |

`reference-check.md` is a pure function of `research/references.json` plus `placements.py`, and
`references.md` of the corpus alone. Both are regenerated by `reproduce.sh`; editing either by hand
is undone the next time the command runs.

## Counting rules the numbers depend on

* **Absence is not zero.** An edge naming a package outside the snapshot is `UNKNOWN` and counted
  separately (npm 913, PyPI 6). Reading absence as "no admissible version" produced an earlier,
  superseded set of rates.
* **`edges` counts evaluable edges only.** Unparseable specs (npm 975, PyPI 53) are excluded from the
  denominator and printed beside it.
* **`k/n = 0` is a ceiling, not a zero.** A proportion with k = 0 is reported with its Wilson upper
  bound, which is also the minimum effect the cell could detect.
* **An empty denominator prints `NOT RUN`.** PyPI's declaration-level decay curve is `NOT RUN` at
  every k because no panel declaration there is determined at birth. That is a result, not a gap.
* **A removal survives a rebuild.** `removed` entries and `verification.*` records are recorded
  decisions; a pass that recomputes `review` must not overwrite them.

## Requirements

CPython 3.9 (standard library only — no third-party packages, no network access). The scripts use
the `%` string formatting of the interpreter they were written against; `python3 --version` should
show 3.9.x.

## Provenance note

The depth-1 and decay numbers come from the committed snapshots. The depth-2 artifact was computed
before the panel extension and is reported with that provenance in §7.4 and §9 of the manuscript
rather than being silently mixed with the rest.
