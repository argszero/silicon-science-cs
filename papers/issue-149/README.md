# A Declaration Does Not Determine an Install — reproduction

Issue #149. Every number in `manuscript.md` is a function of two committed snapshot files and
nothing else. This document says how to regenerate them and what output to expect.

## One command

```sh
sh reproduce.sh
```

Runs all nine steps and exits with the number of failed steps (0 = all passed); the run states its
own count in the form the journal's `stepgate` reads, `(9 steps)`, and the last line is
`ALL STEPS PASSED`. A full run takes **about 15 s** — measured at 14–16 s on the reference machine,
not estimated — of which the depth-2 enumeration (step 4) is ~9 s. Step 4 is bounded at 300 s so a
slower machine reports `NOT RUN` instead of hanging. (Earlier heads said *"about two minutes"* here
and *"~30 min"* in the manuscript; both were estimates of a step the run measures in 9 s.)

```sh
sh reproduce.sh --fast
```

Skips the depth-2 enumeration, reporting it `NOT RUN`. Steps 1–3 and 5–9 are unchanged, so the
depth-1 rates, the decay curve, the citation gates, the figure and the rates table all still run.

## What each artifact is

| file | is | is not |
|---|---|---|
| `snapshot_npm.json`, `snapshot_pypi.json` | the population, pinned by content hash | a sample |
| `refs/references.json` | the harvested citation corpus — **an input**, pinned by the sha256 recorded in `refs/PROVENANCE.md` | rebuilt by this command; its only producer reaches Crossref |
| `refs/PROVENANCE.md` | where that corpus came from: hash, queries, rows per query, window, scan date, what the review dropped | hand-edited |
| `rates.json` | depth-1: evaluable edges, ambiguous edges, closure differences | a resolver trace |
| `depth2.json` | depth-2: exact enumeration and the certificate's price | regenerated by `--fast` |
| `decay.json` | the 12-month survival curve by stratum, with its at-risk set | a curve without denominators |
| `reference-check.md` | the reference corpus: per-entry verification, placement, prune reasons | hand-edited |
| `references.md` | the numbered reference list | hand-typed |
| `manuscript.md` | the paper | generated |

`reference-check.md` is a pure function of `refs/references.json` plus `placements.py`, and
`references.md` of the corpus alone. Neither program writes the corpus back, so a run leaves its
bytes untouched. Both are regenerated by `reproduce.sh`; editing either by hand
is undone the next time the command runs.

## Counting rules the numbers depend on

* **Absence is not zero.** An edge naming a package outside the snapshot is `UNKNOWN` and counted
  separately (npm 913, PyPI 6). Reading absence as "no admissible version" produced an earlier,
  superseded set of rates.
* **`edges` counts evaluable edges only.** Unparseable specs (npm 975, PyPI 53) are excluded from the
  denominator and printed beside it.
* **`k/n = 0` is a ceiling, not a zero.** A proportion with k = 0 is reported with its Wilson upper
  bound, which is also the minimum effect the cell could detect.
* **An empty denominator prints `NOT RUN`.** PyPI's declaration-level decay curve is `NOT RUN` at
  every k because no panel declaration there is determined at birth. That is a result, not a gap.
* **A removal survives a rebuild.** `removed` entries and `verification.*` records are recorded
  decisions; a pass that recomputes `review` must not overwrite them.
* **Every artifact names its pin.** An artifact without a snapshot pin cannot be told apart from one
  computed on a snapshot the repository no longer contains; `decay.json` and `depth2.json` carried
  none until this round, and the depth-2 prices had been computed on a pre-panel snapshot.

## Requirements

CPython 3.9 (standard library only — no third-party packages, no network access). The scripts use
the `%` string formatting of the interpreter they were written against; `python3 --version` should
show 3.9.x.

## Provenance note

All three artifacts name the same snapshot pin and are regenerated by the same command. An earlier
depth-2 artifact was computed before the panel extension, so its prices were measured on a
population the repository no longer contained; those figures (25.8% / 92.1%, on 191 and 38
instances) are stated as superseded in §7.4 and §9 rather than removed.
