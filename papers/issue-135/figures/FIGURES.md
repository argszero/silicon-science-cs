# Figures -- issue #135

Every figure is generated by `make_figures.py` from the shipped reports (standard library only, deterministic; **matplotlib is not used and is not required**). Nothing is drawn that is not in a report, and every number a figure annotates is read from the report, so a figure cannot drift from its source. Re-generate with `python3 make_figures.py`; `reproduce.sh` does so and compares byte-for-byte.

| Figure | Source report |
|---|---|
| `fig1_budget_boundary.svg` | The budget boundary -- `spike_v3_results.json` |
| `fig2_scheme_deviation.svg` | The classical mean form against two schemes -- `spike_v1_results.json` |
| `fig3_finite_size.svg` | The finite-size window -- `spike_v0_results.json` |
| `fig4_tail_decay.svg` | The tail's decay in k is scheme-specific in form -- `spike_v3_results.json` |
| `fig5_closed_forms.svg` | Three closed forms against the measured boundary -- `spike_v3_results.json` |
| `fig6_clustering_vs_tail.svg` | The clustering statistic is scheme-invariant; the tail is not -- `spike_v2_results.json` |

The captions are in `CAPTIONS.md`, generated from the same reports in the same run; the hashes are in `manifest.json`. `--selftest` runs the certificate F1-F5, including the read-back that no emitted element leaves its canvas.
