# issue #114 — The Specificity–Brittleness Frontier of Machine-Checked Specifications

Artifact for the manuscript `manuscript.md`. **One command reproduces everything:**

```bash
bash reproduce.sh          # expected final line: REPRODUCE: ALL GREEN
```

Requirements: `python3` (standard library only — **no pip, no network, no third-party
package**) and a POSIX shell with `cmp`/`shasum`. Runtime ≈ 2 minutes on one CPU core.

## What "reproduce" means here

The word covers three different claims, and they are checked separately because a single
"run it twice and it matched" tolerance proves only the weakest of them.

| # | claim | step | how it is decided |
|---|-------|------|-------------------|
| 1 | the instrument is **deterministic** and its controls can fire | `run_all.sh` | 6 smoke batteries, 5 plant audits, and two independent runs of the decisive run required **byte-identical** |
| 2 | the **committed artefact** is what the code produces | `canonical.py` | regenerate to a temp file and `diff` byte-for-byte against `canonical_results.json` |
| 3 | the **committed figures** and the **manuscript's numbers** are views of that artefact | `make_figures.py --check`, `check_manuscript.py` | 6/6 PNGs regenerated byte-identical + series hashes equal; every claim in the manuscript's Appendix A re-derived from the artefact at the precision the paper prints |

Claim 2 is the one a reader relies on and the one a self-comparison tolerance does **not**
cover: `run_all.sh` proves the run is deterministic, not that the stored numbers came from it.
Both are executed, and each reports the count it read.

## Layout

| file | what it is |
|---|---|
| `manuscript.md` | the paper; every number in it is re-derived by `check_manuscript.py` |
| `toylang.py` | the language and its reference interpreter (semantics = the 256-point table) |
| `mutations.py`, `oracle.py` | the mutation algebra and the semantics-preservation oracle (**no human labels**) |
| `specs.py` | the graded specification family; `s` and `r` are computed from the spec's own text |
| `progspace.py` | the **generated** reference population, with the census of what each filter removed |
| `fast.py` | the bitmask evaluator — its equivalence to `specs.satisfies` is a control, not an assumption |
| `decide.py` | **the decisive run**: 35 (s, r) cells × 96 declared draws, pooled over the references |
| `canonical.py` | writes / checks `canonical_results.json` |
| `plotlib.py`, `make_figures.py` | the figures, drawn by a stdlib PNG writer (see below) |
| `check_manuscript.py` | the manuscript's claims table against the artefact |
| `smoke_*.py`, `plant_*.py` | the batteries and the audits that require each control to be able to fail |
| `frontier.py`, `align.py`, `region_mix.py`, `alignment.py`, `diag_clauses.py` | the Step 1–4 analyses and their controls |
| `run_all.sh`, `reproduce.sh` | the drivers |
| `figures/` | 6 PNGs + `manifest.json` (per-figure PNG sha256, artefact-slice sha256, caption) |

## Tolerance

Exact where it can be exact, and stated where it cannot:

* **Every measurement is exact-in-principle and compared byte-for-byte**: the semantics are
  256-point tables, the oracle's verdict is table equality, the artefact is JSON compared by
  hash, and the figures are PNGs compared by hash. There is no floating-point tolerance in
  steps 1–3.
* **Precision, not tolerance, is the contract for the manuscript**: each claim is compared
  after rounding to the number of decimals the paper prints, so a claim printed as `1.370`
  is checked to 3 decimals and one printed as `0.48` to 2.
* The only sampling in the study is the **population** (a generated reference set) and the
  **draws** (12 pin-set alignments × 8 clause mixes). Both are enumerated rather than
  sampled randomly, so the study reports **bands over the enumerated draws** rather than
  confidence intervals over a random sample; `canonical_results.json` stores the endpoints.

## Why the figures have no plotting library

A figure pipeline that needs a package index at verification time is not "one command", and a
PNG whose bytes depend on the plotting library's version is not reproducible either. The
figures are drawn by `plotlib.py` — a raster canvas, a 3×5 bitmap font and a zlib PNG writer,
all standard library — with no timestamp or metadata chunk, so `figures/manifest.json` can pin
each file by sha256 and `make_figures.py --check` can require a rerun to match it.

## Regenerating after a deliberate change

```bash
python3 decide.py --json canonical_results.json    # recompute the artefact
python3 canonical.py --write                       # or: python3 canonical.py  (check only)
python3 make_figures.py                            # rewrite figures/ + manifest.json
python3 check_manuscript.py                        # re-anchor the manuscript's claims
```

`bash reproduce.sh` is then green again only if the committed files really are the code's
output; a change that moves a number and not the manuscript will fail `check_manuscript.py`,
which is the point.
